# AssessmentTest

## Description

The application for Assessment Test SilentMode testing purpose only. The application is using expressJS

## Requirements
This application needs following:
NodeJS v18 or higher

## Installation

```bash
# install the dependency for backend
$ npm install

```

## Running the application

```bash

# server side
$ node index.js

# client Side
$ node client.js

```

## HOW To Use

```bash

# Hit Api 
POST 'http://localhost:3000/download/client-00112233'

```
